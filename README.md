# Маршрут Вани — итоговое сочинение 2026

Небольшой учебный сайт с литературными произведениями, иллюстрациями, 132 тренировочными темами, развёрнутыми аргументами и заданиями. Работает без сборки и сторонних библиотек.

## Как опубликовать с GitHub Pages

1. Создайте **публичный** репозиторий `vanya-sochinenie-2026`.
2. Распакуйте ZIP-архив и загрузите файлы **в корень** репозитория. Файл `index.html` должен находиться рядом с `sw.js`, `manifest.webmanifest` и двумя иконками.
3. В `Settings → Pages` задайте `Source: Deploy from a branch`, `Branch: main`, `Folder: /(root)`; нажмите `Save`.
4. Откройте `https://ВАШ-ЛОГИН.github.io/vanya-sochinenie-2026/`.
5. На iPhone откройте ссылку в Safari и выберите `Поделиться → На экран «Домой» → Добавить` (при наличии — `Открывать как веб-приложение`).

**Важно:** репозиторий и сайт публичны. Не размещайте здесь личные документы, пароли и переписку. Прогресс ученика хранится локально в браузере, а не в GitHub. При очистке данных браузера он может пропасть — используйте функцию резервного копирования из программы.

### Как обновить

При следующем обновлении достаточно загрузить новые версии файлов с теми же именами и сохранить изменения (`Commit changes`). Если не видно обновлений на iPhone, попробуйте закрыть веб-приложение и открыть заново, а затем проверить сайт в Safari.
